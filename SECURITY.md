# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ |
| < 1.0   | ❌ |

## Reporting a Vulnerability

Please report security vulnerabilities by emailing security@scamshield.dev.

Do not open public issues for security vulnerabilities.

You can expect:
- Acknowledgment within 48 hours
- Regular updates on remediation progress
- Disclosure coordination

## Responsible Disclosure

We kindly ask you to:
1. Not disclose the vulnerability publicly until we have a fix
2. Provide sufficient detail to reproduce the issue
3. Allow reasonable time for remediation

## Security Best Practices

For production deployments, please follow the deployment checklist in DEPLOYMENT_CHECKLIST.md and refer to the security review in docs/SECURITY_REVIEW.md.
